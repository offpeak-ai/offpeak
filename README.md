# board-data

Machine-written branch. The [Night board](../../actions/workflows/nightly.yml)
workflow commits here twice a night — a quote pass at 19:00Z and a mark pass at
06:30Z — because `main` is protected and would reject a nightly bot push.

- `nightly/BOARD.md` — one row per marked night.
- `nightly/<date>-quote.json` / `nightly/<date>-mark.json` — the raw records.

Open, keyless data (NESO carbon intensity; Octopus Agile day-ahead power).
Observation, not trade advice. Generated by `tools/night_report.py` on `main`.
